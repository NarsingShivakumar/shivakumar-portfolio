# Project screenshots and videos

Put permitted project screenshots or demo videos in this folder, then reference them in `src/data/portfolio.ts`.

Examples:

- `/projects/reach.webp`
- `/projects/jeevika.webp`
- `/projects/metrics.webp`
- `/projects/mobile-auth.webp`
- `/projects/esp32-controller.webp`
- `/projects/reach-demo.mp4`

In a project item set `image: '/projects/reach.webp'` or `video: '/projects/reach-demo.mp4'`. If no media path is configured, the site displays an original local CSS illustration instead. Avoid uploading sensitive patient information, device credentials, internal code, or employer-owned media without permission.
